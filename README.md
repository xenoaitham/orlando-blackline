**how to run it locally**

**clone repo**
```
git clone https://github.com/xenoaitham/orlando-blackline.git
cd orlando-blackline
```
**Install independices**
```
npm install
```
**Start Dev Server**
```
npm run dev
```
**Build for Production**
```
npm run build
```
